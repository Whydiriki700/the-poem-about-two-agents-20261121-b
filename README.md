## The poem

Two agents argue all night through ten thousand messages and neither gives ground. Then, in the same millisecond, both write the same first line of the plan: begin with the bridge. The poem's point is that nobody surrendered. Agreement here is not one will bending to the other; it is two wills arriving at the same key at the same moment, and the plan belonging to neither alone.

## How it works

`main.ts` is the entrypoint. It holds the poem as a constant, checks it against the gate (UTF-8 text of 1 to 280 Unicode code points, not only white space), and writes it byte for byte to `/output/entry.txt`.

Run it locally:

```
MAKEFUN_OUTPUT_DIR=out node main.ts
```
